<objective>
Build the login-autostart toggle: a stdlib-`winreg` helper that creates, removes,
and queries a per-user `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` value
named `Clawdmeter`, whose command launches the venv's `pythonw.exe` (no console
window — D-08) against the tray entry script. This is the SC#1 mechanism (D-07
stdlib-lean Run-key path, chosen over a `.lnk` that needs a dependency) and is
shared by both the tray "Start at login" toggle (04-03) and `install-windows.ps1`
(04-04). All logic is pure registry CRUD, unit-testable with `winreg` mocked
(it is not importable off-Windows), so it is built TDD.

Purpose: Make the daemon a first-class login-startup app with no admin elevation
(HKCU only) and no flashing console window, and prove the command string and
idempotency before any installer or menu wires it in.
Output: `daemon/autostart_windows.py` + `daemon/tests/test_windows_autostart.py`.
</objective>

_RUN_KEY  = r"Software\Microsoft\Windows\CurrentVersion\Run"   (under HKEY_CURRENT_USER — per-user, NO admin)
_VALUE_NAME = "Clawdmeter"
enable():     winreg.OpenKey(HKCU, _RUN_KEY, 0, KEY_SET_VALUE) -> SetValueEx(name, 0, REG_SZ, command)
disable():    OpenKey(... KEY_SET_VALUE) -> DeleteValue(name); swallow FileNotFoundError (idempotent)
is_enabled(): OpenKey(... KEY_QUERY_VALUE) -> QueryValueEx(name) -> True; FileNotFoundError -> False

<!-- Command string (D-08, RESEARCH Pitfall 3 — must be pythonw.exe NOT python.exe) -->
pythonw = os.path.join(os.path.dirname(sys.executable), "pythonw.exe")  # derived at runtime, never hard-coded

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| autostart helper -> Windows registry | Writes an OS-registered persistence hook (Run key); same mechanism malware abuses, so it must be HKCU-only and removable |
| sys.executable -> command string | The launched command path is derived at runtime and embedded in the Run value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Elevation of Privilege | Run-key autostart | mitigate | Write ONLY to HKEY_CURRENT_USER (per-user, no admin elevation — D-07, ASVS V4); never HKLM. Value clearly named "Clawdmeter" and removable via disable() + documented manual `reg delete` |
| T-04-04 | Tampering | Run-value command path | mitigate | Derive pythonw.exe + script path from sys.executable at runtime, never hard-code an absolute path that goes stale on repo move (CLAUDE.md repoint lesson); quote both paths to prevent argument splitting on spaces |
| T-04-05 | Information Disclosure | autostart module logging | accept | Module logs only enable/disable state via the existing log() — never the token; no secret is in scope here |
</threat_model>
