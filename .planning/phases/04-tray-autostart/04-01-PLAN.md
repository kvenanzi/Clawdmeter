<objective>
Build the deterministic icon-asset layer for the tray: parse the existing
`firmware/src/logo.h` RGB565A8 brand logo into a Pillow RGBA image, expand
RGB565->RGB888 with correct rounding, and composite a per-state colored corner
bubble (green=connected / amber=scanning / red=error) onto the constant brand
mark (D-02, D-03). This is the visual substrate the tray runtime (04-03)
consumes to show connection status (SC#2). All logic here is pure and unit-
testable off-Windows (Pillow only, no pystray/winreg), so it is built TDD.

Purpose: Reuse the real on-device brand mark for the tray icon instead of
inventing new art (D-03 + user-profile note), and make the state->image mapping
provably correct before the tray wires it in.
Output: `daemon/icon_assets.py` (pure helpers) + `daemon/tests/test_windows_icon.py`.
</objective>
